# CS1151-A4-List-Processing




PURPOSE OF THIS PROGRAM:  
 This program generates a list of random integers based on a user-specified length.  
 Since the third-to-the-last digit of my UMD ID is 2, the program splits the list  
 into two separate lists: OddList (containing all odd values) and EvenList (containing  
 all even values). It then identifies which of the two lists is longer and sorts that list  
 in descending order.  
  
 Additionally, because my digit is 2 (which is in the range 0–4), the program finds and  
 prints the most frequently occurring value in the longer list.  
  
 The program is tested with three different list sizes:  
   - 11 numbers  
   - 25 numbers  
   - 98 numbers (calculated from my UMD ID as (10 × 9) + 8)
